# KeyNest

KeyNest is an iOS application for managing passwords and passkeys locally
on your device. All data is stored on-device only and is never transmitted
to any external server. Sensitive information is protected using AES-GCM
encryption with the data-encryption key wrapped by the iPhone or iPad's
Secure Enclave.
