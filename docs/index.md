# KeyNest

**Offline-first password & passkey manager for iPhone and iPad.**

Your credentials live on this device, encrypted with AES-256-GCM. The
encryption key is wrapped by the Secure Enclave. KeyNest has no network
code — no server to breach, no analytics, no third-party SDKs.

## What KeyNest does

- Stores passwords with up to 10 custom fields per entry
- Generates and stores passkeys (iOS 17+) for sites that support them
- Fills credentials anywhere via the iOS AutoFill system
- Unlocks with Face ID / Touch ID / device passcode

## What KeyNest doesn't do

- No accounts, no sign-up, no cloud sync
- No advertising, no analytics, no telemetry
- No third-party SDKs, no embedded trackers
- No data collection of any kind

The App Store privacy nutrition label is the single category
**"Data Not Collected"**.
